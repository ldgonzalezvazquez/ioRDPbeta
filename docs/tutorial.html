1. Introduction and ideal workflow ↑ contents

RDP io is the browser edition of the RDP5/RDP6 workflow: detect recombination signals in a nucleotide alignment and reduce them to a minimal set of plausible unique events. as in the manual, the automatic result is only a preliminary hypothesis: review it event by event.

  1. Prepare a good dataset and a good alignment (outside RDP io; e.g. MAFFT).
  2. Open the alignment with Open... (or Example).
  3. Set methods and linear/circular genome in Options....
  4. Launch ▶ Run ▾ → Full exploratory scan.
  5. Review the Unique recombination events list and the Recombination info panel.
  6. Correct breakpoints / roles if needed; Accept or Reject.
  7. After corrections, Re-scan masked to reformulate non-accepted events.
  8. Complement with Trees, VisRD, Identity, Breakpoints, Rec. rate, PHI, FUBAR, SCHEMA, QvR.
  9. Save the project / “recombination-free” alignments with Save ▾.
In a hurry? Stay on this page, or RDP5Manual.pdf.

1. Introducción y flujo ideal ↑ índice

RDP io es la edición en el navegador del flujo de trabajo de RDP5/RDP6: detectar señales de recombinación en un alineamiento de nucleótidos y reducirlas a un conjunto mínimo de eventos únicos plausibles. Como en el manual, el resultado automático es solo una hipótesis preliminar: hay que revisarla evento a evento.

  1. Preparar un buen dataset y un buen alineamiento (fuera de RDP io; p. ej. MAFFT).
  2. Abrir el alineamiento con Open... (o Example).
  3. Ajustar métodos y genoma lineal/circular en Options....
  4. Lanzar ▶ Run ▾ → Full exploratory scan.
  5. Revisar la lista Unique recombination events y el panel Recombination info.
  6. Corregir breakpoints / roles si hace falta; Accept o Reject.
  7. Tras correcciones, Re-scan masked para reformular eventos no aceptados.
  8. Complementar con Trees, VisRD, Identity, Breakpoints, Rec. rate, PHI, FUBAR, SCHEMA, QvR.
  9. Guardar proyecto / alineamientos “libres de recombinación” con Save ▾.

2. Dataset and alignment ↑ contents

Compile a good dataset

  • At least 3 sequences; enough diversity (not identical).
  • Ideal: pairs with >70 % identity; avoid pairs <60 % (false positives from poor alignment).
  • Remove identical duplicates; the manual’s approximate threshold Y = (2 ln 4X) / L helps avoid overly close pairs (X = number of sequences, L = length).
  • In RDP io: Edit ▾ → Auto-mask for detection power masks very close sequences (MaskSeq=1) so multiple-testing correction is less severe.

Make a good alignment

  • Use MAFFT (or Clustal / MUSCLE / POA) before opening the file here; RDP io does not align.
  • Visually check gappy or poorly conserved regions; stagger or remove unrecoverable columns.
  • In Options... you can enable alignment consistency checking (Check alignment consistency / RealignFlag).
All detection methods are very sensitive to poor alignment: it often appears as false “recombination”. More detail: see here in the manual.

2. Dataset y alineamiento ↑ índice

Compilar un buen dataset

  • Mínimo 3 secuencias; diversidad suficiente (no idénticas).
  • Ideal: pares con >70 % identidad; evitar pares <60 % (falsos positivos por mal alineamiento).
  • Eliminar duplicados idénticos; el umbral aproximado del manual Y = (2 ln 4X) / L ayuda a no incluir pares demasiado cercanos (X = nº de secuencias, L = longitud).
  • En RDP io: Edit ▾ → Auto-mask for detection power enmascara secuencias muy cercanas (MaskSeq=1) para endurecer menos la corrección múltiple.

Hacer un buen alineamiento

  • Usa MAFFT (o Clustal / MUSCLE / POA) antes de abrir el archivo aquí; RDP io no alinea.
  • Revisa a ojo regiones gappy o poco conservadas; “stagger” o elimina columnas irrecuperables.
  • En Options... puedes activar la comprobación de consistencia de alineamiento (Check alignment consistency / RealignFlag).
Todos los métodos de detección son muy sensibles al mal alineamiento: suele aparecer como “recombinación” falsa. Más detalle: ver aquí en el manual.

3. Open an alignment ↑ contents

  1. Click Open... and choose FASTA, NEXUS, PHYLIP, CLUSTAL, or a project .json / .rdp / .rdp5.
  2. Alternatively: Load project..., Recent ▾, or Example (synthetic recombinant alignment).
  3. Check the left Alignment panel (sequence count, length) and the Alignment tab (MSA).
Recognised formats (see here in the manual): PHYLIP, FASTA, CLUSTAL, NEXUS, etc. Drag-and-drop onto the window also works.

3. Abrir un alineamiento ↑ índice

  1. Pulsa Open... y elige FASTA, NEXUS, PHYLIP, CLUSTAL, o un proyecto .json / .rdp / .rdp5.
  2. Alternativa: Load project..., Recent ▾, o Example (alineamiento sintético recombinante).
  3. Comprueba el panel izquierdo Alignment (nº de secuencias, longitud) y la pestaña Alignment (MSA).
Formatos reconocidos (ver aquí en el manual): PHYLIP, FASTA, CLUSTAL, NEXUS, etc. Arrastrar y soltar el archivo sobre la ventana también funciona.

4. Options… — preliminary setup ↑ contents

  1. Open Options....
  2. Under General: indicate whether sequences are circular or use the Linear genome preset.
  3. Enable primary detection methods. By default it is reasonable to use RDP + GENECONV + MaxChi; for datasets <50 sequences you can add Chimaera, Bootscan, SiScan and 3Seq.
  4. Bootscan / SiScan can run in secondary mode (only confirm signals from other methods) via secondary scope — faster on large datasets.
  5. Review the maximum acceptable p-value and multiple-comparison correction (Bonferroni / step-down).
  6. Data processing: Polish breakpoints, Disentangle overlapping (only if there is little recombination; can loop), realistic/conservative recombinant grouping.
  7. Adjust windows/steps per method if you seek short tracts (<200 bp). MaxChi/Chimaera ≈ 2× the RDP window; Bootscan/SiScan similar to each other.
  8. Confirm with OK and return to the main toolbar.
For occasional users, the desktop defaults are usually enough. Change mainly methods, linear/circular, windows and tree models.

4. Options… — configuración preliminar ↑ índice

  1. Abre Options....
  2. En General: indica si las secuencias son circular o usa el preset Linear genome.
  3. Activa los métodos de detección primaria. Por defecto es razonable usar RDP + GENECONV + MaxChi; en datasets <50 secuencias puedes añadir Chimaera, Bootscan, SiScan y 3Seq.
  4. Bootscan / SiScan pueden ir en modo secundario (solo confirmar señales de otros métodos) vía secondary scope — más rápido en datasets grandes.
  5. Revisa p-valor máximo aceptable y corrección por comparaciones múltiples (Bonferroni / step-down).
  6. Data processing: Polish breakpoints, Disentangle overlapping (solo si hay poca recombinación; puede entrarse en bucles), agrupación realistic/conservative de recombinantes.
  7. Ajusta ventanas/pasos por método si buscas tractos cortos (<200 bp). MaxChi/Chimaera ≈ 2× la ventana de RDP; Bootscan/SiScan similares entre sí.
  8. Confirma con OK y vuelve a la barra principal.
Para usuarios ocasionales, los valores por defecto del escritorio suelen bastar. Cambia sobre todo métodos, lineal/circular, ventanas y modelos de árboles.

5. Run — full exploratory scan ↑ contents

  1. Click ▶ Run ▾ → Full exploratory scan (all methods enabled in Options).
  2. There are two phases: (1) signal detection per method; (2) merging into unique events (GetSupers).
  3. If it takes too long: ■ Stop — you keep partial results.
  4. The Run menu also offers single-method scans (Automated RDP, GENECONV, …) and Manual shortcuts (opens the Profiles tab).

After the scan you will see the Recombination overview (colour blocks), the unique-events table and the Recombination info panel with p-values, per-method confirmation table and uppercase warnings (doubtful breakpoints, possible misalignment, unsampled parental, etc.).

5. Run — escaneo exploratorio completo ↑ índice

  1. Pulsa ▶ Run ▾ → Full exploratory scan (all methods enabled in Options).
  2. Hay dos fases: (1) detección de señales por método; (2) fusión en eventos únicos (GetSupers).
  3. Si tarda demasiado: ■ Stop — conservarás resultados parciales.
  4. El menú Run también ofrece escaneos de un solo método (Automated RDP, GENECONV, …) y atajos a Manual (abre la pestaña Profiles).

Tras el escaneo verás el Recombination overview (bloques de color), la tabla de eventos únicos y el panel Recombination info con p-valores, tabla de confirmación por método y avisos en mayúsculas (breakpoints dudosos, posible mal alineamiento, parental no muestreado, etc.).

6. Interpreting unique events and Confirm ↑ contents

The manual warns of four typical automatic-analysis mistakes: misplaced breakpoints; parental labelled as recombinant; over-grouping of descendants of the same ancestor; or under-grouping (several events where there is one). Earlier errors in that list are more serious: correct from event 1.

  1. Select events in the Unique recombination events list or with Go ▾ (Previous / Next / Go to best unaccepted).
  2. Read Recombination info: breakpoints, major/minor parents, confirmation table (how many methods support the signal) and warnings.
  3. Filter by number of methods (≥N) in the event list (ConsensusProg) if you want to be stricter.
  4. Compare plots in the overview / profile tabs to see whether peaks match the pink edges of the recombinant tract.
The desktop “confirmation table” appears here in the info panel and in the event detail (methods that detected the signal and p-values).

6. Interpretar eventos únicos y Confirm ↑ índice

El manual advierte cuatro errores típicos del análisis automático: breakpoints mal situados; parental etiquetado como recombinante; sobre-agrupación de descendientes del mismo ancestro; o infra-agrupación (varios eventos donde hay uno). Los errores al principio de la lista son más graves: corrige desde el evento 1.

  1. Selecciona eventos en la lista Unique recombination events o con Go ▾ (Previous / Next / Go to best unaccepted).
  2. Lee Recombination info: breakpoints, major/minor parents, confirmation table (cuántos métodos apoyan la señal) y advertencias.
  3. Filtra por nº de métodos (≥N) en la lista de eventos (ConsensusProg) si quieres ser más estricto.
  4. Compara gráficos en el overview / pestañas de perfiles para ver si los picos coinciden con los bordes rosa del tracto recombinante.
La “confirmation table” del escritorio aparece aquí en el panel de información y en el detalle del evento (métodos que detectaron la señal y p-valores).

7. Accept / Reject ↑ contents

  1. Choose the scope in the on dropdown: unique event (whole group) or this detection.
  2. Accept — mark the hypothesis as reviewed/accepted (distinct border; skipped when navigating if Skip accepted is on).
  3. Reject — hide / discard the signal (recoverable with Accept).
  4. Correct roles with Edit ▾: Swap daughter ↔ minor/major, Swap major ↔ minor, Place beginning/ending breakpoint, Merge events, Re-identify recombinants.
Accept only when (1) the recombinant is correct, (2) breakpoints are reasonable and (3) the grouping of sequences sharing the same signal is correct.

7. Accept / Reject ↑ índice

  1. Elige el alcance en el desplegable on: unique event (todo el grupo) o this detection.
  2. Accept — marcas la hipótesis como revisada/aceptada (borde distintivo; se omite al navegar si activas Skip accepted).
  3. Reject — ocultas / descartas la señal (recuperable con Accept).
  4. Corrige roles con Edit ▾: Swap daughter ↔ minor/major, Swap major ↔ minor, Place beginning/ending breakpoint, Merge events, Re-identify recombinants.
Acepta solo cuando (1) el recombinante es el correcto, (2) los breakpoints son razonables y (3) el agrupamiento de secuencias con la misma señal es correcto.

8. Re-scan masked and Re-Check all ↑ contents

  1. After Accept of a corrected event, click Re-scan masked. It masks regions of accepted events and re-scans the rest (approximate equivalent of desktop DoRDP redo / MissingData).
  2. Re-Check all re-runs a full scan while keeping Accepts (RCheckMnu).
  3. Continue with the next unaccepted event (Go ▾ → Next / Skip accepted).
Save often with Save project (.json) or Save ▾ → Project as RDP5 / RDP text — see here in the manual.

8. Re-scan masked y Re-Check all ↑ índice

  1. Tras Accept de un evento corregido, pulsa Re-scan masked. Enmascara las regiones de eventos aceptados y vuelve a escanear el resto (equivalente aproximado al DoRDP redo / MissingData del escritorio).
  2. Re-Check all relanza un escaneo completo manteniendo los Accept (RCheckMnu).
  3. Continúa con el siguiente evento no aceptado (Go ▾ → Next / Skip accepted).
Guarda a menudo con Save project (.json) o Save ▾ → Project as RDP5 / RDP text — ver aquí en el manual.

9. Trees — validate the recombinant ↑ contents

  1. Open the Trees tab.
  2. Compare a tree of the recombinant tract (minor) with one of the flanks (major). The recombinant usually “moves” between clades more than the parentals.
  3. Choose NJ / UPGMA / ML (HKY+Γ) / Bayes (MH-NNI) according to patience and dataset size.
  4. SH/KH (RELL) tests are available in the panel for region vs flank.
  5. Interaction: tip click = name+distance; internal click = swap children; Shift+click = reroot; Copy for clipboard.
On the desktop the Trees button is on the toolbar; here it lives as a tab, with the same role of contrasting alignment partitions defined by the selected event’s breakpoints.

9. Trees — validar el recombinante ↑ índice

  1. Abre la pestaña Trees.
  2. Compara un árbol del tracto recombinante (minor) con uno de los flancos (major). El recombinante suele “moverse” más entre clados que los parentales.
  3. Elige NJ / UPGMA / ML (HKY+Γ) / Bayes (MH-NNI) según paciencia y tamaño del dataset.
  4. Pruebas SH/KH (RELL) disponibles en el panel para región vs flanco.
  5. Interacción: clic en tip = nombre+distancia; clic interno = swap hijos; Shift+clic = reroot; Copy para portapapeles.
En el escritorio el botón Trees está en la barra; aquí vive como pestaña, con la misma función de contrastar particiones del alineamiento definidas por los breakpoints del evento seleccionado.

10. VisRD ↑ contents

VisRD (Lemey et al., 2009) visualises phylogenetic “occupancy” density along the alignment. In RDP io: VisRD tab — compute and draw the profile; export CSV via Save ▾ → Plot CSV: VisRD.

Useful as a secondary check of an already detected event; the manual notes that VisRD Highway / GENECONV plots are not the best for refining breakpoints (prefer MaxChi, Chimaera, BURT, Bootscan).

10. VisRD ↑ índice

VisRD (Lemey et al., 2009) visualiza la densidad de “ocupación” filogenética a lo largo del alineamiento. En RDP io: pestaña VisRD — calcula y dibuja el perfil; exporta CSV vía Save ▾ → Plot CSV: VisRD.

Útil como comprobación secundaria de un evento ya detectado; el manual indica que los plots VisRD Highway / GENECONV no son los mejores para afinar breakpoints (prefiere MaxChi, Chimaera, BURT, Bootscan).

11. Identity plot ↑ contents

Identity plot tab: identity / distance plot by window (equivalent to DNA Distance Plots / ManDistPltMnu). Choose windows and step in Options → Plots or in the panel. Curve crossings help place breakpoints.

Export with Save ▾ → Plot CSV: identity plot, or PNG from Graphics.

11. Identity plot ↑ índice

Pestaña Identity plot: gráfico de identidad / distancia por ventana (equivalente a DNA Distance Plots / ManDistPltMnu). Elige ventanas y paso en Options → Plots o en el panel. Los cruces de curvas ayudan a situar breakpoints.

Exporta con Save ▾ → Plot CSV: identity plot, o PNG desde Graphics.

12. Profiles / Manual — triplet scans ↑ contents

  1. Profiles / Manual tab (also from ▶ Run ▾ → Manual GENECONV / Bootscan / …).
  2. Choose the method and triplet (query + two parentals).
  3. Click Run method for the sliding profile and triplet detections.
  4. Compare MaxChi/Chimaera peaks with the edges of the selected event in the overview.
This is the equivalent of “Check using” + manual scans (Man*Mnu) on the desktop.

12. Profiles / Manual — scans de un triplete ↑ índice

  1. Pestaña Profiles / Manual (también desde ▶ Run ▾ → Manual GENECONV / Bootscan / …).
  2. Elige el método y el triplete (query + dos parentales).
  3. Pulsa Run method para el perfil deslizante y detecciones del triplete.
  4. Compara picos MaxChi/Chimaera con los bordes del evento seleccionado en el overview.
Este es el equivalente a “Check using” + scans manuales (Man*Mnu) del escritorio.

13. Breakpoints — hotspots / coldspots ↑ contents

Breakpoints tab: distribution of detected breakpoints, confidence bands under random recombination, and hot/cold p-value track (BPDistPltMnu / BPDistPltMnu2). Requires events (ideally prior Accepts).

To associate breakpoints with genes/ORFs, load a site-set with Site set (permutation enrichment test).

13. Breakpoints — hotspots / coldspots ↑ índice

Pestaña Breakpoints: distribución de breakpoints detectados, bandas de confianza bajo recombinación aleatoria, y track de p-valores hot/cold (BPDistPltMnu / BPDistPltMnu2). Requiere eventos (idealmente Accept previos).

Para asociar breakpoints a genes/ORFs, carga un site-set con Site set (prueba de enriquecimiento por permutación).

14. Rec. rate / LDHat ↑ contents

  1. Rec. rate tab: recombination-rate profile (LDHat INTERVAL port; π-hat fallback option).
  2. StartRho / BlockPen and window/step parameters in Options... (LDHat / Plots).
  3. Toolbar button LDHat test: global CONVERT+PAIRWISE test (desktop-style MsgBox message).
This is a TypeScript browser port, not the Windows LDHat binary .

14. Rec. rate / LDHat ↑ índice

  1. Pestaña Rec. rate: perfil de tasa de recombinación (port de LDHat INTERVAL; opción de fallback π-hat).
  2. Parámetros StartRho / BlockPen y ventana/paso en Options... (LDHat / Plots).
  3. Botón de barra LDHat test: test global CONVERT+PAIRWISE (mensaje tipo MsgBox del escritorio).
Es un browser port TypeScript, no el binario LDHat de Windows .

15. PHI test ↑ contents

PHI test (Bruen et al., 2006) — Pairwise Homoplasy Index over the whole alignment (≥4 sequences). Result in the status / info panel. Complements window methods: indicates global evidence of recombination without locating breakpoints.

Related compatibility matrices: Compat. matrix tab (Jakobsen, Bruen/PHI sites, RF, SH, modularity, event matrices, MaxChi/LARD BP, etc.).

15. PHI test ↑ índice

PHI test (Bruen et al., 2006) — Pairwise Homoplasy Index sobre todo el alineamiento (≥4 secuencias). Resultado en el panel de estado / info. Complementa los métodos de ventana: indica si hay evidencia global de recombinación sin localizar breakpoints.

Matrices de compatibilidad relacionadas: pestaña Compat. matrix (Jakobsen, Bruen/PHI sites, RF, SH, modularity, matrices de eventos, MaxChi/LARD BP, etc.).

16. FUBAR — codon selection ↑ contents

FUBAR runs a FUBAR-like analysis (Dirichlet grid + EM/MCMC in the browser) on the codon alignment. Export per-site posteriors: Save ▾ → Plot CSV: FUBAR site posteriors.

Ensure the correct reading frame (Options → SCHEMA frame). This is not the HyPhy FUBAR binary; it is the documented coverage substitute.

16. FUBAR — selección en codones ↑ índice

FUBAR lanza un análisis tipo FUBAR (rejilla Dirichlet + EM/MCMC en el navegador) sobre el alineamiento codonado. Exporta posteriores por sitio: Save ▾ → Plot CSV: FUBAR site posteriors.

Asegura marco de lectura correcto (Options → SCHEMA frame). No es el binario HyPhy FUBAR; es el sustituto documentado en coverage.

17. SCHEMA — folding disruption ↑ contents

  1. Optional: Load PDB for a Cα contact map (better than sequence-only fallback).
  2. SCHEMA — intra-protein disruption (SCHEMAMnu).
  3. SCHEMA II — inter-chain contacts (requires PDB).
  4. SCHEMA DNA — nucleic-acid folding disruption (DNASCHEMAMnu).

As in the HIV example in the manual, a low p-value suggests that real breakpoints fall where they disrupt folding less than random recombinants.

17. SCHEMA — disrupción de plegado ↑ índice

  1. Opcional: Load PDB para mapa de contactos Cα (mejor que el fallback solo-secuencia).
  2. SCHEMA — disrupción intra-proteína (SCHEMAMnu).
  3. SCHEMA II — contactos inter-cadena (requiere PDB).
  4. SCHEMA DNA — disrupción de plegado de ácido nucleico (DNASCHEMAMnu).

Como en el ejemplo HIV del manual, un p-valor bajo sugiere que los breakpoints reales caen donde disruptían menos el plegado que recombinantes aleatorios.

18. Save — alignment and project variants ↑ contents

Save ▾ menu (maps to desktop Save* menus):

  • Alignment as FASTA — full alignment.
  • recombinant sequences removed (SIndex 1) — drops recombinant daughters.
  • recombinant regions stripped (SIndex 3) — removes recombinant tracts.
  • distributed / ExRec (SIndex 7).
  • split by recombinants / breakpoints — one file per piece.
  • only enabled / masked / disabled — by MaskSeq 0/1/2.
  • PHYLIP / NEXUS / CLUSTAL formats; translated AA; ORF/gene; ancestral Fitch or ML.
  • Event CSV, plot CSV, PNG / copy clipboard.
  • Project .json, .rdp, .rdp5.

Shortcut: Save project saves alignment + events (Accept/Reject) + options + PHI.

18. Save — variantes de alineamiento y proyecto ↑ índice

Menú Save ▾ (mapeo a menús Save* del escritorio):

  • Alignment as FASTA — alineamiento completo.
  • recombinant sequences removed (SIndex 1) — quita hijas recombinantes.
  • recombinant regions stripped (SIndex 3) — elimina tractos recombinantes.
  • distributed / ExRec (SIndex 7).
  • split by recombinants / breakpoints — un archivo por pieza.
  • only enabled / masked / disabled — según MaskSeq 0/1/2.
  • Formatos PHYLIP / NEXUS / CLUSTAL; AA traducidas; ORF/gen; ancestral Fitch o ML.
  • CSV de eventos, CSV de plots, PNG / copy clipboard.
  • Proyecto .json, .rdp, .rdp5.

Atajo: Save project guarda alineamiento + eventos (Accept/Reject) + opciones + PHI.

19. QvR / Manual — query vs reference ↑ contents

  1. QvR / Manual tab.
  2. Assign roles: query, reference, or excluded (MaskSeq ≠ 0 is treated as excluded).
  3. ▶ Run restricted scan — only triplets defined by those roles (QvR or subset mode), with methods active in Options.

Corresponds to desktop RecMnu Query vs Reference and ManualSeqSelect. Useful when you already know a set of non-recombinant references.

Additional manual scans

Besides Profiles, ▶ Run ▾ → Manual * opens the chosen method in Profiles for a triplet. PhylPro has its own PhylPro tab (distance correlation / PXoverF).

19. QvR / Manual — query vs reference ↑ índice

  1. Pestaña QvR / Manual.
  2. Asigna roles: query, referencia, o excluida (MaskSeq ≠ 0 se trata como excluida).
  3. ▶ Run restricted scan — solo los tripletes definidos por esos roles (modo QvR o subset), con los métodos activos en Options.

Corresponde a RecMnu Query vs Reference y ManualSeqSelect del escritorio. Útil cuando ya conoces un conjunto de referencias no recombinantes.

Scans manuales adicionales

Además de Profiles, el menú ▶ Run ▾ → Manual * abre el método elegido en Profiles para un triplete. PhylPro tiene pestaña propia PhylPro (correlación de distancias / PXoverF).

Citations and notes ↑ contents

If you publish results obtained with RDP io or RDP5, please cite RDP5:

Martin DP, Varsani A, Roumagnac P, Botha G, Maslamoney S, Schwab T, Kelz Z, Kumar V & Murrell B (2021) RDP5: a computer program for analyzing recombination in, and removing signals of recombination from, nucleotide sequence datasets. Virus Evolution 7: veaa087. doi:10.1093/ve/veaa087

A new publication for this browser version (RDP io) will also be included when it is available.

Also cite the specific detection method you used (RDP, GENECONV, Bootscan, MaxChi, Chimaera, SiScan, 3Seq, PHI, VisRD, LDHat, SCHEMA, FUBAR, …). For the recommended reference list, see here in the manual.

RDP io reimplements the workflow in TypeScript in the browser. It does not launch the Windows desktop binaries.
